还不清楚 Norm？一文搞定

大模型里的归一化（Normalization）听起来玄乎，其实就是"把每层的数据拉回一个稳定的尺度"。从 LayerNorm、RMSNorm 到 Pre/Post-Norm、QK-Norm，再到 2025 年的 DyT 无归一化新浪潮，这一篇带你看懂整个家族，每一张图都画清楚向量形状。

1为什么要归一化？

一句话：深度网络训练不稳定的根源，是每一层的输入分布一直在变（术语叫内部协变量偏移，Internal Covariate Shift）。前一层参数一更新，后一层的输入分布就"搬家"，后一层只能不断重新适应，导致收敛慢、对学习率敏感。

归一化层的本质，就是在每层内部把激活值重新中心化、重新缩放，让分布稳定。它能带来三个直接好处：

允许更大的学习率，训练更快更稳
缓解梯度消失 / 爆炸，能堆很深
降低对初始化的敏感度，更鲁棒
关键问题：沿哪个维度做统计？ 这是所有 Norm 的分水岭。

2BatchNorm：为什么在 LLM 里被弃？

BatchNorm（BN）是 CV 领域的标配，它沿 batch 维统计每个通道的均值与方差：

$$ \hat{x}_{:,d} = \frac{x_{:,d}-\mu_d}{\sqrt{\sigma_d^2+\epsilon}}, \qquad \mu_d = \frac{1}{N}\sum_{n=1}^N x_{n,d} $$

它把"同一批里所有样本"混在一起统计。这在图像里没问题，但在 LLM 里有三个致命伤：

  • ① 对 batch size 极度敏感 —— LLM 显存受限、batch 往往很小，统计量噪声大、归一化不准。
  • ② 训练/推理不一致，自回归生成直接失效 —— 推理是逐个 token 生成的（batch=1），批统计退化成单样本统计，与训练分布严重偏离。
  • ③ 破坏变长与位置结构 —— 把不同位置的 token 混在一起统计，抹掉了位置独立性，padding token 还会污染统计量。
一句话：BN 依赖"批内同分布 + 固定尺寸 + 非生成式推理"，与 LLM 的"小批、变长、自回归生成"本质冲突。因此 Transformer 从诞生起就选 LayerNorm。

3LayerNorm：Transformer 的经典答案

LayerNorm（LN）沿特征维、对每个 token 独立归一化，完全不依赖 batch。对单个 token 向量 x ∈ ℝ^d：

$$ \mu = \frac{1}{d}\sum_{i=1}^d x_i,\qquad \sigma^2 = \frac{1}{d}\sum_{i=1}^d (x_i-\mu)^2 $$
$$ \operatorname{LayerNorm}(x) = \gamma \odot \frac{x-\mu}{\sqrt{\sigma^2+\epsilon}} + \beta $$

它做两步：先减均值 μ（中心化），再除标准差 σ（缩放），最后乘可学习 γ、加可学习 β（仿射，让输出落回任意范围）。

图 2：LayerNorm 两步走 —— 先中心化再缩放，形状全程保持 (d,)。γ、β 形状也都是 (d,)。
早期 Transformer、BERT、GPT-2 都用 LayerNorm。注意 γ 与 β 的形状是 (d,)，与 token 向量逐元素相乘。

4RMSNorm：现代 LLM 的主流

RMSNorm（Zhang & Sennrich, 2019）是 LayerNorm 的极简版：去掉"减均值"这一步，也去掉偏置 β。它只用均方根（Root Mean Square）控制向量整体尺度：

$$ \operatorname{RMS}(x) = \sqrt{\frac{1}{d}\sum_{i=1}^d x_i^2 + \epsilon} $$
$$ \operatorname{RMSNorm}(x) = \gamma \odot \frac{x}{\operatorname{RMS}(x)} $$

为什么可以省掉均值？经验上，Transformer 里的激活值均值本来就接近 0，中心化几乎不带来收益，省掉它换来更少算子、更少参数、更快，效果还持平甚至更好。

图 3：RMSNorm —— 一个标量 1/RMS(x) 缩放整个向量，只留一个可学习 γ。比 LayerNorm 少了均值统计和 β。
结果：现代 LLM（LLaMA 系、Mistral、Gemma、Qwen 等）几乎清一色采用 Pre-Norm + RMSNorm。它已成为 2024–2026 所有主流开源模型的标配。

6Pre-Norm vs Post-Norm：放哪比用哪种更关键

Transformer block 里有两个子层（Attention 和 FFN），外面套着残差连接。Norm 放在残差的前面还是后面，决定了训练稳定性。这比选 LayerNorm 还是 RMSNorm 更重要。

图 4：Post-Norm 先残差相加再归一化；Pre-Norm 先归一化再进子层，残差流保持原始状态。现代 LLM 全用 Pre-Norm。
Post-Norm

先 x + F(x) 再归一化。早期结构简单，但深层模型训练不稳定，激活值在残差相加后尺度容易失控。

Pre-Norm

先归一化再进子层，最后加残差。残差路径保持"身份映射"，梯度流更干净、深层更易训练，因此成为现代主流。

一个小代价：纯 Pre-Norm 在较浅层时性能通常略逊于 Post-Norm，所以有研究尝试混合方案（见下文的 HybridNorm）。

7其他重要（& 冷门）变体

QK-Norm / QueryNorm

不在 hidden state 上归一化，而是对 Attention 的 Q 和 K 单独做归一化。原始 softmax 点积随维度增大容易饱和（softmax 退化成一端接近 1、其余接近 0）。对 Q、K 做 L2 归一化后再乘一个可学习标量，能让注意力分布更"均匀、可塑"。Gemma、部分新模型使用 QK-Norm。

$$ \operatorname{Attention}(Q,K,V) = \operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V $$
图 5：QK-Norm —— 把 Q、K 归一成单位向量，再乘以可学习缩放，等价于用"余弦相似度"做注意力。

相关术语：QueryNorm（只归 Q）、QKV-Norm（Q、K、V 都归）是 QK-Norm 的扩展。另外 FlashNorm 还能把带 QKV-Norm 的模型进一步加速。

Sandwich Norm / DeepNorm：为更深的网络而生

  • Sandwich Norm（夹心归一化）：在子层前后各放一个 Norm（pre 一个、残差相加前再一个），即 x' = x + Norm(f(Norm(x)))，用于稳定很深的网络。
  • DeepNorm：在残差连接处对激活按系数 α 缩放，配合特殊初始化让上千层 Transformer 也能训练（GLM-130B 用过）。
$$ \operatorname{DeepNorm}(x) = \operatorname{LayerNorm}\big(\alpha\cdot x + \operatorname{Sublayer}(x)\big) $$

HybridNorm 与其他混合方案

纯 Pre-Norm 训练稳但浅层性能略差，纯 Post-Norm 性能好但训练难。于是出现了混合方案：HybridNorm 在 Attention 里用 QKV-Norm（类 Pre-Norm 的稳定），在 FFN 上用 Post-Norm（类 Post-Norm 的性能），在密集和 MoE 模型上都取得更好效果。

ScaleNorm / Embedding Norm / Final Norm / 注意力缩放

  • ScaleNorm：只归一化范数、不做中心化，思路与 RMSNorm 类似，是更早的简化尝试。
  • Embedding Norm：对 token embedding（或 embedding 相加后）做一次归一化，BERT 常见。
  • Final Norm：最后一层 block 之后再归一化，再接语言模型头，几乎每个 decoder-only LLM 都有。
  • 注意力缩放（attention scaling）：√d_k 缩放严格说不是 Norm，但它也是一种尺度控制，常和 Norm 一起被讨论。

8新方向：DyT —— 不要 Norm 也能训？

2025 年 Meta 的一篇工作（Zhu et al.）提出了一个激进但惊艳的想法：直接用激活函数替换 Norm。他们观察到 LayerNorm 的输入输出关系往往呈 S 形（类似 tanh），于是提出 DyT（Dynamic Tanh）：

$$ \operatorname{DyT}(x) = \tanh(\alpha \cdot x), \qquad \alpha \text{ 是可学习标量} $$

DyT 是一个逐元素操作：小值时近似线性缩放，大值时被 tanh 压扁（squash），从而模拟归一化的效果，但完全不计算激活统计量，因此更快。实验表明它在视觉与语言 Transformer 上都能匹配甚至超过带归一化的模型。

图 6：DyT 用一个可学习标量 α 的逐元素 tanh 模拟归一化，去掉了统计量计算。

相关后续工作：DyISRU（Dynamic Inverse Square Root Unit，从 RMSNorm 精确导出的逐元素等价形式）、BHyT（Bound tanh 变体，进一步结合方差近似提升速度）。这条"无归一化"路线目前还在探索，传统 Norm 仍是绝对主流。

10工程实现：那些坑

  • 用 fp32 算统计量：即使激活是 bf16/fp16，RMS / 方差也要在 fp32 下算，否则训练激进时容易 NaN。算完再转回原精度。
  • eps 不能省：ϵ 防除零，也影响数值稳定性，常用 1e-5 ~ 1e-6。
  • 用 rsqrt：torch.rsqrt(x)（倒数平方根）底层走专用 CUDA 指令，比 1/sqrt(x) 快。
  • PyTorch 原生支持：PyTorch 2.4+ 内置 nn.RMSNorm，直接用即可。
  • Final Norm 别漏：最后一个 block 后通常还要一个 RMSNorm 再接 LM head。

RMSNorm 的标准实现（LLaMA 风格）

# x: [..., d]，在最后一维做归一化；统计量在 fp32 下计算更稳
class RMSNorm(nn.Module):
    def __init__(self, d, eps=1e-6):
        super().__init__()
        self.eps = eps
        self.weight = nn.Parameter(torch.ones(d))   # shape (d,)

    def forward(self, x):
        x = x.float()                            # 提精度，稳定方差
        rms = torch.sqrt(x.pow(2).mean(-1, keepdim=True) + self.eps)
        x = x * torch.rsqrt(x.pow(2).mean(-1, keepdim=True) + self.eps)
        return (self.weight * x).to(x.dtype)

11总结 & 参考资料

一句话收尾：LLM 的归一化家族 = "哪种"（LayerNorm → RMSNorm）+ "放哪"（Pre/Post-Norm）+ 若干变体（QK-Norm、DeepNorm、SandwichNorm）+ 新浪潮（DyT 无归一化）。现代主流答案是 Pre-Norm + RMSNorm，记住这一条，其余都是锦上添花。
