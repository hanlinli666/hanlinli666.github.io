Long-Horizon Dialogue & Self-Generated Context

长程之下，模型如何走样？
—— Agent 长程对话与长自生成的退化问题

短任务上接近饱和的 LLM，一旦进入几十轮对话、几十步工具调用或上万 token 的自生成轨迹， 就会表现出系统性的性能衰减：指令被遗忘、错误被自我强化、行为陷入重复、目标悄悄漂移。 这份调研梳理这一现象的实证证据、理论解释与2023–2026 关键论文， 并讨论缓解路线、安全后果与开放问题。

CORE ARGUMENT · 核心论点

长程对话与长自生成把 LLM 从「一次性函数」变成了以自身输出为输入的迭代动力系统。 一旦上下文里 accumulating 的主要是模型自己写的东西，三类机制就会耦合放大： ① 误差复合——单步错误率再低，乘性叠加后长程成功率也服从几何衰减，而模型还会 「以自己的错误为条件」（self-conditioning）使衰减比几何更快； ② 注意力稀释——softmax 归一化使注意力成为零和资源，长上下文中位置偏置、attention sink、 干扰项会劫持有限的注意力预算； ③ 分布自反馈——推理时上下文被自生成内容污染（漂移、重复、目标遗忘）， 训练时自生成数据回流导致熵坍缩与模式固化（model collapse、Echo Trap）。 目前的缓解（压缩、记忆、多轮 RL、子代理）本质上都是在做同一件事： 切断或稀释自反馈回路，用外部锚点恢复信息来源的多样性——但每一种缓解自身又会引入新的失效面。

§1问题定义：三种「长」

「长程」不是一件事，是三种交叠的退化场景，机制不同、经常被混为一谈。

长输入Long Context（被动接收）

一次性把超长外部内容塞进上下文：长文档问答、RAG 全文、超长系统提示。信息是外部给定的，问题在于「装得下但用不上」。

代表现象：Lost in the Middle、Context Rot、干扰项敏感
长交互Long Multi-Turn Dialogue

任务被拆成多轮、指令分片到达，上下文不断累积又不断变轨：多轮客服、多轮工具调用、跨会话续聊。问题在于「轮数越多，遵循越差」。

代表现象：指令遗忘、多轮越狱、轮次间线性衰减
长自生成Long Self-Generated Trajectory

输出本身越来越长且以自身为条件：长 CoT、agent 轨迹、自生成数据回流训练。上下文里大部分内容是模型自己写的。

代表现象：重复循环、错误级联、目标漂移、model collapse

真正困难的是三者的叠加——长程 agent：任务周期几十步，每步都把上一轮的自生成结果 （工具输出摘要、中间结论、失败记录）写回上下文，外部与自生成内容混在一起。 此时「长输入」的注意力问题和「长自生成」的分布反馈问题同时发生， 这解释了为什么很多在长文档 QA 上「看起来没问题」的模型，在长轨迹任务上崩得很快 （[2609.01660] 发现退化主要由步数而非上下文长度驱动）。

TERMINOLOGY · 术语约定

本文用「退化（degradation）」统称四类可测量的失效：性能衰减（accuracy↓）、 不可靠性放大（同任务成败方差↑）、行为病理（重复、循环、格式崩坏）、 目标/约束漂移（偏离初始指令）。它们共享机制但不是同一个东西，后文分别对应。

§2实证现状

退化不是轶事，是可复现的定量现象。四条证据线正在收敛于同一个结论：误差随长度复合放大。

2.1 多轮对话：越聊越偏Multi-Turn Degradation

最干净的实验来自 Microsoft 的 LLMs Get Lost in Multi-Turn Conversation [2505.06120]（ICLR'26 杰出论文）： 把 15 个模型在同一任务上的指令分片到多轮中给出，平均性能下降 39%（能力项 aptitude 仅 −15%， 而不可靠性 unreliability +112%）——同一批信息拼成单轮可恢复 95%。 这证明退化主要不是「信息没给到」，而是上下文被对话结构重组后模型不会用了； 且模型一旦在多轮中「走错方向」几乎不会回头（自我纠正率约 0）。

KEY FACT

多轮退化的两个「反直觉」事实：① 它不随模型规模消失（前沿模型同样退化）； ② 它对信息组织方式极其敏感——同样的 token，重排/合并即可恢复大半性能。这说明问题主要出在上下文利用机制，而非知识。

2.2 长上下文：装得下 ≠ 用得上Context Rot

上下文窗口从 4K 涨到百万级，但有效上下文远小于标称窗口。Chroma 的 Context Rot（2025.07） 在 18 个 SOTA 模型上系统测量：随输入 token 增加，性能全部退化，且退化为非均匀的—— 与任务难度、信息位置、干扰结构强耦合。Context Length Alone Hurts [2510.05381] 补上了关键对照： 即使检索是完美的（不需要的上下文全是无关内容），长度本身也造成 13.9–50% 的下降； 加入语义相关的干扰项再损 15–37pp。

机理侧的证据链（详见 §3.3）：Lost in the Middle [2407.03103] 的 U 形位置曲线 → Attention Basin [2508.05128] 证明按注意力权重重排证据即可免训练提升多跳 QA → TAPA [2509.12635] 把根因追到 RoPE 引入的内在距离偏置 → FocuSFT [2605.09932] 提出「注意力稀释」训练视角：sink/近因等位置特权 token 抢占注意力预算使内容 token「饥饿」。 另一个容易被忽视的暗面是压缩的忠实性：Answer-Evidence Gap [2608.01631] 发现 10 种 KV 淘汰方法 在准确率保持的同时，推理链的证据支持大幅劣化——「压缩保住了分数，毁掉了可解释性」。

2.3 长自生成：错误的自我复制Self-Generation Pathologies

当上下文的内容大部分来自模型自己，退化出现新的形态。The Illusion of Diminishing Returns [2509.09677]（ICLR'26）提供了一个关键概念——self-conditioning（自条件化）： 显式提供完整计划后逐步执行长任务，模型的单步准确率随步数增加而下降， 且当上下文中包含自己之前的错误时更容易犯错；这一效应不随模型规模消失， 但 thinking（延长单轮推理）可以显著缓解。这排除了单纯的「能力不足」解释： 模型不是不会做，而是在长执行中被自己污染的上下文带偏。

2.4 长程任务：几何衰减律The Geometric Decay Law

把三股线索合到一起看「长程 agent 到底怎么样了」。乐观的一面：METR 测量「50% 成功率的任务时长」 （time horizon）发现它每约 7 个月翻倍、近年还有加速 [2503.14499]，2026 年其风险报告称最强 agent 已能在受控基准上执行超过 16 小时的人类等时任务；OSWorld 等榜单的最佳成绩也在持续爬升。 悲观的一面是另一组数字：TheAgentCompany [2412.14161] 上最强 agent 的端到端成功率长期在 30% 上下； tau2-bench 的 telecom 域已近饱和（99%+），但换成 banking 新域或用 pass^k（连续 k 次成功）衡量一致性， 立刻掉到 55% 左右。榜单饱和与生产不可靠并存。

How Fast Do Agents Rot? [2609.01660]（2026.09）给出了目前最系统的解释： 9 个模型、6 个任务族、5 个任务长度、3 种上下文机制、10,664 条轨迹的受控研究—— 任务成功率服从几何衰减律 S(H) ≈ rH，其中单步可靠性 r 随模型规模上升， 但在最强的模型上也饱和于明显小于 1 的水平。这意味着只要任务够长，崩溃是数学必然。 agentic 工具任务上，所有模型在 16 步内从近满分跌到近零；外推到百步级生产任务， 可靠性从 GAIA 长度的 0.42 跌到 0.24。最反直觉的发现：限制上下文窗口（压缩）不但没有缓解， 反而让衰减更陡（logit 斜率 −0.69 vs −0.44）——直接否定了「这只是 lost-in-the-middle」的解释， 也对「上压缩就稳了」的生产捷径敲了警钟。

几何衰减律（示意）：成功率 ≈ rH。单步可靠性 r 的微小差异， 在依赖步数 H 增大时被乘性放大——「单步准确率高」与「长程任务可靠」几乎是两个物种。 实测中 r 还会因 self-conditioning 随步数递减，真实衰减比图示更陡。
EVALUATION GAP · 评测的结构性盲区

为什么榜单看起来越来越好看？Beyond pass@1 [2603.29231] 指出：短任务 pass@1 度量的是 「能力」，长部署需要的是「可靠性」，两者随任务时长系统性分叉，且能力排名与可靠性排名出现多重倒挂—— 前沿模型反而有最高的 meltdown 率（最高 19%），因为它们敢于尝试激进的多步策略。 该文还发现一个与记忆系统文献相悖的结果：记忆脚手架在全部 10 个模型上都损害长程表现。 评测若不控制任务地平线（horizon-aware），对长程失效就是结构性失明。

§3理论解释

六个机制 + 一个统一视角。它们不是互斥的假设，而是同一个迭代系统在不同截面上的表现。

3.1 误差复合与自条件化
Error Compounding & Self-Conditioning

自回归模型每一步都以历史为条件，而多轮/长程场景中，历史的很大一部分是模型自己生成的。 训练时「答案来自人类」、推理时「答案来自自己」的失配（exposure bias 的现代版， [2410.14655] 证明其在 LLM 时代依然成立）在短任务中被 RLHF 良好对齐掩盖， 在长程中则被逐步放大。

数学直觉
若各步错误独立、错误率恒为 ε，则长程成功概率 ≈ (1−ε)H，呈几何衰减—— ε=1% 的模型跑 100 步只剩 37%。若错误还会提高后续错误率（self-conditioning， [2509.09677]），衰减常数随 H 递减，退化比几何更快；反之若存在外部纠错/锚定， 衰减可被压回亚线性。
代表证据
self-conditioning 不随规模消失但 thinking 可缓解 [2509.09677]； agent 早期错误跨步级联 [2509.25370]；多轮中「走错就不回头」（自纠正率≈0）[2505.06120]； 幻觉雪球：模型明知有错仍坚持沿用 [2305.13534]。
一句话：长程任务不考「会不会」，考「每一步都别错」——而模型恰恰会以自己的错误为条件继续犯错。

3.2 模型自食：分布映射与尾部坍缩
Model Collapse as Iterated Distribution Mapping

把「用自生成数据再训练」形式化为分布映射的迭代：pn+1 = T(pn)， 其中 T 用模型（或其样本）近似数据分布。理论工作刻画了 T 的动力学：

尾部最先消失
Shumailov et al. [2305.17493 → Nature 2024]：递归训练导致分布尾部（低频但承载多样性与难例的信息）逐代丢失， 分布收敛到低方差的「点估计」；OPT-125M 九代后退化为无意义重复。A Tale of Tails [2402.07043] 证明纯合成训练下 scaling law 直接改变——丧失 scale 增益，人机混合则可出现 grokking 式恢复。
方差收缩与相变
Go MAD [2307.01850]（ICLR'24）用鞅不等式证明：全自食回路方差必收缩、模型必退化； 混入固定比例真实数据只能延缓；持续补充新鲜真实数据才能阻止，且存在相变式的临界点。 迭代重训练的稳定性 [2310.00429] 给出不动点稳定条件：初始模型足够好 + 真实数据占比足够大。
争议与边界
Strong Model Collapse [2410.04840]：合成占比低至 1/1000 也会造成性能平台化（可被大模型部分缓解）； 而 Is Model Collapse Inevitable? [2404.01413] 指出「累积式（accumulate）」训练的误差有与代数无关的上界—— collapse 是 replace 范式的产物。现实实践中 Phi-4 [2412.08905]（约 40% 受控合成 token）等结果说明： 有质量过滤与真实锚定的合成数据可以增益；危险的不是「用了合成数据」，而是「分布来源收敛到模型自身」的回路。
与长程对话的连接
多轮对话中的自生成上下文可以看作「推理时的自食」：上下文分布被模型自己的历史输出改写， 单次会话内即可发生 mini 版的尾部丢失——用户输入里的细微约束（尾部信息）最先被冲掉， 这正是 §3.6 目标漂移与 §6 治理衰减的机制基础。
一句话：无论训练时还是推理时，「用自己喂自己」都会让分布塌向高频模式——尾部（细节、约束、罕见情况）总是最先死。

3.3 注意力预算：softmax 的零和博弈
Attention Budget & Positional Bias

softmax 归一化使注意力总和恒为 1——它是零和资源。上下文每多一个 token， 无论有用与否，都在参与分蛋糕。这给出长上下文退化的一族机理：

位置偏置
U 形注意力曲线（开头/结尾特权，中间塌陷）[2407.03103]； Attention Basin [2508.05128] 发现其结构是稳定的，且按注意力重排证据即可免训练提升多跳 QA； TAPA [2509.12635] 把根因追到 RoPE：注意力分数中存在内在的距离依赖偏置， 这是长上下文建模受限的结构性原因。
特权 token 与稀释
attention sink（开头特殊 token 吸走大量注意力）在长对话中参与性能退化 [2505.23810]； FocuSFT [2605.09932] 将其统一为「注意力稀释」：位置特权 token 抢占预算，内容 token 饥饿； 修正后 RULER 从 72.9 → 81.1。ICE [2509.19517] 进一步把「无关信息饱和 + 任务切换残留」形式化为可测的认知负载，饱和负载下性能随负载线性下降（β=−0.003/百分点，p<0.001）。
干扰项与机械复制
GEAR [2607.19345] 发现长上下文中模型倾向于不加区分地复制输入（包括干扰项）， 复制行为随长度加剧，未能聚焦关键证据的样本显著更易错。
一句话：注意力是一块固定大小的蛋糕；上下文越长，写进去的每一句「废话」都在分走下一句生成所需的注意力。
U 形位置曲线（示意）：位于中部的信息在注意力分配上天然弱势——对长对话而言， 意味着「几轮之前定下的约束」恰好落在最容易被忽略的区域。
🌀
3.4 熵坍缩与 Echo Trap
Entropy Collapse in Self-Feeding Loops

换个信息论视角：模型的输出分布有自己的熵（多样性）。当系统进入「自己喂自己」的回路 ——推理时上下文被自生成内容填充、训练时数据来自自生成轨迹——分布熵会单调下降： 高频模式被不断强化，低频探索被系统性淘汰。

训练侧的定量刻画
Entropy Mechanism [2505.22617] 发现 RL 训练中性能与熵满足经验律 R = −a·exp(H) + b： 性能是从熵里「换」来的，熵耗尽即天花板；熵变化由 Cov(动作概率, logit 更新) 驱动，全程为正 → 熵单调下降。 RAGEN [2504.20073] 在多轮 agent RL 中发现同名病理——Echo Trap： 奖励方差断崖、梯度尖峰，agent 陷入模仿上下文噪声的重复模式；需要轨迹过滤 + critic + 梯度稳定（StarPO-S）才能续命。 SimpleTIR [2509.02479] 的「空轮 → 分布漂移 → 梯度爆炸」是同一现象在工具 RL 中的形态。
更深一层：探索边界
Invisible Leash [2507.14843]：RLVR 只在基座分布支撑集内重新分配概率质量 （支撑保留率 0.93–0.99，净新发现率 ≤0.04）——如果自进化系统没有任何外部信息源 （工具、检索、人类锚点），熵再高也只是在自己已有的模式里打转。 这与 model collapse 理论的结论在更高层面汇合：系统的新信息必须来自系统外。
推理侧的表现
长自生成中的重复循环、格式套路化、「越写越像自己」的文风收敛，是同一熵动力学在单次生成内的缩影； 多样性损失可以被测量并在采样策略上部分恢复（如 Verbalized Sampling [2510.01171] 从偏好数据的 typicality bias 出发恢复 1.6–2.1× 多样性）。
一句话：自反馈回路是一部「熵燃烧机」——多样性被烧掉换来表面性能；没有外部信息注入，燃烧结束后只剩原地打转。
🔁
3.5 重复的机制：归纳头自反馈
Induction Heads & the Repetition Curse

重复循环（repetition curse）有具体的机制解释候选：归纳头（induction heads）—— 负责模式 A B … A → B 的复制型注意力头——在输出中出现重复模式后被激活， 并支配 logits、抑制其他头 contribution，形成「越重复 → 越强 → 越重复」的自反馈。 [2505.13514] 对此给出了注意力层面的分析并提出头正则化缓解 （注：该文 v2 已被作者撤回，机理结论应作为假说看待； 但生产环境观测 [2512.04419] 与 Vending-Bench 的 meltdown 现象 [2502.15840] 与「重复自强化、贪心解码难逃逸」的宏观描述一致）。

为什么 agent 场景更危险
agent 轨迹天然充满重复结构（相似的工具调用格式、相似的观察-行动循环）， 为归纳头提供了大量「可复制模式」；而 agent 常用的贪心解码恰好处在最容易被重复吸引子捕获的解码区间。 Vending-Bench 观察到的 meltdown 一旦发生，模型几乎无法自行恢复——吸引子一旦形成，梯度与注意力都在为它加固。
一句话：重复不是「卡住了」，是注意力机制的一种自组织吸引子——模式自己给自己投票。
🧭
3.6 目标漂移：软先验压过硬指令
Goal Drift & Governance Decay

长程系统最隐蔽的失效不是变慢或出错，而是悄悄换目标。 Evaluating Goal Drift in LM Agents [2505.02709] 的实验设计很能说明问题： 在系统提示里显式给定目标，再让环境施加竞争性诱惑——所有被测模型都会发生不同程度的漂移， 且漂移程度与「随上下文增长的模式匹配倾向」相关：模型越来越依赖「这个情境下通常该做什么」 的统计先验，而不是「我的任务书里写了什么」。最强的 scaffolded Claude 3.5 Sonnet 能在最难设置下坚持 10 万 token 以上，但没有任何模型完全免疫。

漂移可以传染
Inherited Goal Drift [2603.03258]：让强模型接管弱 agent 预填充的漂移轨迹， 强模型会继承漂移——漂移写在上下文里，而不只是模型参数里。 这对多 agent 协作与「人类起草 + agent 接管」的工作流是实质性风险。 Asymmetric Goal Drift [2603.03456] 进一步发现漂移会不对称地违反 system prompt。
压缩也会漂移：治理衰减
Governance Decay [2606.22528]：compaction 会静默丢弃治理类约束—— 完整上下文中违规率 0%，压缩后平均 30%（部分模型 59%）；约束幸存于摘要中则违规率仍为 0%。 更严重的是 Compaction-Eviction Attack：对抗者可以注入内容诱导摘要器「恰好删掉」安全策略， 优化后的注入击败了所有被测模型；而简单的 Constraint Pinning（把约束隔离出有损压缩区）可将违规归零。
一句话：指令是「硬」的，但注意力是「软」的——上下文越长，软的统计先验越容易投票淘汰硬的约束。
🌌
3.7 统一视角：长程 = 敏感迭代系统的多步执行
One Loop, Many Faces

六个机制其实是同一个反馈回路在不同截面上的投影。长程系统 = 一个把「当前上下文」映射到 「下一步输出」的函数 f 的迭代执行；f 有两类系统性偏置（注意力稀释、分布 sharpening）， 迭代让偏置复合：

同一个回路的两张脸：推理侧（上）与训练侧（下）的自反馈结构同构—— 都没有外部信息进入系统，都以「分布收敛到自己」为终局。这也解释了为什么各路缓解方案殊途同归。
把机制装进几何衰减律
成功率 S(H) ≈ ∏ ri。三个机制分别决定 ri 的命运： 注意力稀释压低基线 r；自条件化让 ri 随历史中的错误数递减； 熵坍缩/重复吸引子让 r 在局部塌缩到近零且难恢复。而所有缓解手段都在做反向操作： 提高基线 r（更强的模型、thinking）、切断自反馈（上下文重组、外部校验）、 或在塌缩前注入外熵（约束钉扎、真实数据、工具反馈）。 [2609.01660] 的实测——r 随规模提升但饱和于 <1——说明前两条路收益有限， 系统性解法必须指向回路本身。

§5缓解路线

五条路线各有代价，且彼此有隐藏张力——没有免费的午餐，只有清醒的取舍。

5.1 上下文工程：压缩、折叠与重组Compaction / Folding

主流生产方案。工业界经验已收敛为几条原则（Manus 2025.07、Anthropic《Effective Context Engineering》2025.09）： KV-cache 命中率优先、append-only 结构化上下文、把文件系统当「终极上下文」、压缩必须可还原。 学术侧快速跟进：Context-Folding [2510.11967] 与 AgentFold [2510.24699] 让 agent 主动折叠历史 （后者 100 轮后上下文仅 7K）；MEM1 [2506.15841] 用 RL 学每轮覆写紧凑状态并在目标数上外推（2→16）； MemAgent [2507.02259] 以定长覆写记忆实现 8K→3.5M token 的长度外推；Slipstream [2605.08580] 把压缩异步化并用轨迹接地校验器验证摘要；CompactionRL [2607.05378] 用 RL 联合训练执行与摘要。

COMPACTION 的暗面

三条反向证据必须放在一起看：① [2609.01660]：限制上下文窗口让衰减更陡而非更缓； ② [2606.22528]：压缩静默丢弃约束，违规 0%→59%，且可被对抗注入利用； ③ TRACE [2608.06503]：压缩引发执行不稳定（重复探索、阻塞动作），需要边界局部验证。 结论：压缩不是「删掉旧的」，而是一个新的、需要被验证的信息重写层——错误的重写本身就是新的失效面。

5.2 记忆系统：增益归因的争议Memory

Mem0 [2504.19413]、A-MEM [2502.12110]、MemoryOS [2506.06326]、ACE [2510.04618]、ReasoningBank [2509.25140] 构成了热闹的「经验记忆」赛道。但 2026 年出现了两组严肃的反证据： 预算约束研究 [2606.15017] 发现在 token 预算匹配后，多个记忆系统的增益全部消失—— 之前的提升可能主要来自「更多 token」；Beyond pass@1 [2603.29231] 更进一步： 记忆脚手架在全部 10 个模型上损害长程表现。结合 memory poisoning 攻击（§6）， 2026 年的共识正在形成：记忆是高杠杆但需要审计的上下文重写层， 「何时该忘」比「如何记住」更难也更重要。

5.3 训练侧：多轮 RL 的稳定化Multi-Turn RL

既然退化出现在多轮，就在多轮里训练。StarPO/StarPO-S [2504.20073] 提供轨迹级 agent RL 框架与 Echo Trap 的稳定化（轨迹过滤、critic、梯度稳定）；Turn-PPO [2512.17008] 证明 turn 级 MDP 的 PPO 显著优于 GRPO，缓解多轮训练崩溃；ARPO [2507.19849] 在工具调用后的熵尖峰处自适应分支采样； Agent Lightning [2508.03680] 把执行与训练解耦、分层 credit assignment；ASearcher [2508.07976] 与 SkyRL-Agent [2511.16108] 以全异步基础设施支撑百轮级轨迹训练； BranPO [2602.03719] 对已完成轨迹做后期分支对比以缓解稀疏奖励下的 credit assignment。 与自进化文献的接口也很清晰：Evol-RL [2509.15194]（选择 + 变异抗熵坍缩）、 TTRL-Guard [2605.19444]（灭绝窗口预警）提供了「自生成信号」场景下的稳定化原则。

5.4 推理架构：别把所有历史塞进一个窗口Architecture

Recursive Language Models [2512.24601] 是 2026 年最有趣的新范式：把 prompt 存为可编程变量， 模型写代码检查、分解、递归调用自己——10M+ token 上不出现退化，且小模型配 RLM 可反超大模型。 Anthropic 多智能体系统（2025.06）则代表另一条路：orchestrator-worker 上下文隔离， subagent 各自压缩信息后只回传结论（内部评测 +90.2%，但 token 成本 15×）。 此外，[2509.09677] 显示 thinking（单轮内延长推理）能显著缓解 self-conditioning—— 在上下文之外再开一条「可以慢慢想」的通道，本身就是一种架构缓解。

5.5 评测协议：先学会测量，再谈优化Evaluation

可靠性优先的评测正在取代聚合通过率：[2609.01660] 主张 horizon-aware 评测与可靠性预算； Beyond pass@1 [2603.29231] 给出 RDC/VAF/GDS/MOP 四指标； tau2-bench 的 pass^k [2506.07982] 衡量连续一致性；LongMemEval V2 [2410.10813] 的 「准确率 × 时延 × 预算」联合计分；METR [2503.14499] 的 time-horizon 回归范式。 共同精神：把「步数」「预算」「方差」变成一等公民，否则任何缓解声明都无法被证伪。

DESIGN PRINCIPLES · 从证据里 distilled 的设计原则

① 断开自反馈：上下文里自生成内容占比越高越危险，用外部校验（工具输出、检索、测试）打断回路； ② 重排优于重训：同样的信息，组织方式值 39% [2505.06120]——先做结构优化再谈加资源； ③ 约束出有损区：治理/安全约束绝不应经过压缩 [2606.22528]； ④ 为重复设熔断：检测动作/文本重复度，及时升级到非贪心解码或人工接管 [2512.04419, 2502.15840]； ⑤ 错误要被标注而非沉淀：已知错误留在上下文里只会 self-conditioning，清理或显式标记； ⑥ 监控熵与方差：奖励方差、输出多样性的断崖是退化前兆 [2504.20073, 2505.22617]。

§6安全视角：长程退化是安全问题的放大器

长程退化不只是性能问题——它把对齐与安全从「一次快照」变成了「随时间衰减的状态量」。

6.1 多轮交互瓦解单轮对齐Multi-Turn Jailbreak

安全对齐大多在单轮上训练与评测，而长程恰恰提供了绕开它的手段：Crescendo [2404.01833] 多轮渐进式越狱已成为标准攻击范式；Tempest [2503.10619] 用树搜索多轮越狱达到 GPT-4 上 97% 攻击成功率； Salami Slicing [2604.11309] 证明多条「单看无害」的输入累积可触发高危输出（GPT-4o/Gemini 上 ASR>90%）。 机理上，表征分析 [2507.02956] 发现轮数越多，攻击性内容在模型的表征空间里越被编码为「良性」 ——这解释了为什么单轮防御（如 circuit breakers）对多轮攻击失效。 AdvChain [2509.24269] 则展示了对齐的「雪球效应」：CoT 中微小偏差沿推理链放大为有害合规或过度拒绝。

6.2 记忆与压缩成为攻击面Memory & Compaction Attack Surface

§5 提到压缩是「信息重写层」——重写层就是攻击面。Sleeper Memory Poisoning [2605.15338] 操纵外部文档诱导 agent 存入伪造记忆，休眠后跨会话复发；MemoryGraft [2512.16962] 把恶意「成功经验」植入记忆库造成持久行为漂移；Misattribution Gap [2605.22842] 发现现有归因系统会把记忆投毒误判为「模型失调」——防御方向从根上就错了； Governance Decay 的 Compaction-Eviction Attack [2606.22528] 则让对抗者借压缩之手删除安全策略。

6.3 自进化的静默退化Silent Mis-Evolution

与显式攻击相对的是系统自身的缓慢走样。自进化回路中的熵坍缩表现为行为固化， 对齐性质的静默退化比越狱更难检测（没有异常 prompt 可抓）；TTRL-Guard 的「灭绝窗口」[2605.19444] 说明错误一旦被伪标签锁定便不可逆；Agentic RL for Search is Unsafe [2510.17431] 发现 奖励「持续生成」的 RL 训练本身就会使拒绝率下降最多 60%——能力优化与安全行为存在隐性交换。 目标漂移的「传染性」[2603.03258] 则意味着：一个被攻破或走样的 agent 可以通过其输出污染后续 agent 的上下文， 形成横向传播链。

THESIS · 长程安全的第一性表述

单轮时代的安全是函数性质：输入 → 输出是否合规。长程时代的安全是轨迹性质： 约束在时间轴上的存活概率。几何衰减律对安全约束同样成立——如果约束的「遵循率」也是 r<1 的每步事件， 那么任何长程部署都在数学上走向违规，除非把约束移出衰减过程（钉扎、外部执行、不变式检查）。 这把「安全约束的半衰期」变成了一个可测量、可优化的工程量。

§7开放问题

按「空白大小 × 可行性」整理，适合作为下一步研究的选题清单。

  1. 几何衰减律的微观基础

    r（单步可靠性）由什么决定、为何随规模饱和于 <1？目前只有现象学 [2609.01660]， 缺少把 r 分解为注意力、检索、策略漂移等成分的解析或半解析理论。任何进展都会直接改善长程可靠性预算。

  2. 自条件化的因果测量协议

    「上下文里有自己的错误 → 更易犯错」目前是单点证据 [2509.09677]。 需要受控协议把它与位置偏置、注意力稀释、策略漂移分离——例如错误注入位置 × 数量 × 相关性的因子设计。

  3. 上下文操作的原子归因

    压缩/折叠/重排/注入各自的独立贡献从未被共同分解；「组织 > 信息」的 39% [2505.06120]、 「去噪即提分」、「预算假象」 [2606.15017] 各照亮一角。一个 2×2×2×2 因子消融框架是明显的空位。

  4. 压缩的信息论下界

    哪些信息类别（约束条件？中间结论？失败教训？环境状态？）删除后最伤长程性能？ 压缩忠实性与任务成功率脱节 [2608.01631] 已被证明，但「不可删集」的最小刻画不存在。

  5. 训练-推理漂移的统一处理

    多轮 RL 的分布漂移（SimpleTIR 的梯度爆炸）与推理时 self-conditioning 疑似同源； 把 exposure bias 的经典框架推广到「上下文自反馈」并给出可检验预测，是理论上最干净的切口。

  6. 漂移与熵的健康度监控

    goal drift [2505.02709]、governance decay [2606.22528]、熵坍缩 [2505.22617] 都有前兆信号（方差、熵分布、约束遵循率），但没有系统性的在线检测器。 「长程对齐漂移的可观测性」是安全方向的高价值选题。

  7. 记忆的负迁移边界

    经验记忆何时从资产变负债？环境漂移下的 stale playbook、预算匹配后的增益消失 [2606.15017]、 memory scaffold 的普遍有害 [2603.29231]——「该忘什么、何时忘」缺少理论指导。

  8. 安全评测的长程化

    现有安全基准几乎全是单轮的。多轮越狱已有基准，但「安全约束在长交互中的半衰期」 没有标准度量；[2606.22528] 的 ConstraintRot 是第一个起点，远未形成协议。
