Large Language Model Linear Attention Qwen3-Next

Qwen Gated DeltaNet 实现细节与 Chunkwise 并行推导

深入解析 Qwen3-Next 混合注意力架构中的 Gated DeltaNet（GDN）层——从核心公式、门控机制、实现细节，到 Chunkwise 并行训练的完整数学推导。

📖 技术深度解析 ⏱ 约 25 分钟阅读 🧮 含数学公式推导

一、架构概述

Qwen3-Next（及后续 Qwen3.5/3.6 系列）采用混合注意力机制，在 48 层中每 4 层为一组，其中 3 层用 Gated DeltaNet（线性注意力），1 层用 Gated Attention（标准 GQA 全注意力），比例为 75% : 25%。

  • Gated DeltaNet（75%）：负责长序列的高效建模，复杂度 $O(L)$，推理时状态固定
  • Gated Attention（25%）：放在关键语义锚点，保证精准召回能力
💡

该设计将 256K 上下文的计算开销减少约 95%。

二、核心公式：Gated Delta Rule

$$S_t = S_{t-1}\big(\alpha_t(I - \beta_t k_t k_t^\top)\big) + \beta_t v_t k_t^\top$$ $$o_t = S_t\, q_t$$

2.1 符号说明

符号维度含义
$S_t$$\mathbb{R}^{d_v \times d_k}$状态矩阵（记忆），每个头一个，固定大小，不随序列增长
$S_{t-1}$$\mathbb{R}^{d_v \times d_k}$上一时刻的记忆
$q_t$$\mathbb{R}^{d_k}$查询向量（读取记忆的"钥匙"）
$k_t$$\mathbb{R}^{d_k}$键向量（写入/擦除记忆的"地址"）
$v_t$$\mathbb{R}^{d_v}$值向量（要写入的内容）
$\alpha_t$标量 $\in (0,1)$全局遗忘门（控制整体记忆保留率）
$\beta_t$标量 $\in (0,1)$局部更新强度（在线学习率）
$I$$\mathbb{R}^{d_k \times d_k}$单位矩阵
$o_t$$\mathbb{R}^{d_v}$输出向量

其中 $t$ 是 token 索引（非层索引），在一个 GDN 层内从 1 遍历到 $L$。

2.2 门控参数 $\alpha_t$ 和 $\beta_t$ 的计算

$\alpha_t$ 和 $\beta_t$ 都是 data-dependent（内容驱动）的，由当前 token 的 hidden_states $x_t$ 投影后经非线性变换得到。

$\beta_t$ 的计算（局部更新强度）

$$\beta_t = \sigma(b_t), \quad b_t = W_{\beta}\, x_t \in \mathbb{R}^{N_v}$$

其中 $\sigma$ 是 sigmoid 函数，$W_\beta \in \mathbb{R}^{N_v \times d}$ 是投影权重，$N_v$ 为 value head 数。每个 value head 独立一个 $\beta_t$ 标量，控制写入强度。

$\alpha_t$ 的计算（全局遗忘门）

$$\alpha_t = \exp(g_t), \quad g_t = -\exp(A_{\log}) \odot \text{softplus}(a_t + dt_{bias})$$

$$a_t = W_{\alpha}\, x_t \in \mathbb{R}^{N_v}$$

其中：

  • $A_{\log} \in \mathbb{R}^{N_v}$：可学习参数，初始化为 $\log(\text{Uniform}(0, 16))$，控制每个头的基础衰减率
  • $dt_{bias} \in \mathbb{R}^{N_v}$：可学习偏置，初始化为 1
  • $a_t$：由当前 token 内容投影得到，实现内容驱动的动态衰减
  • $\text{softplus}$ 保证衰减速率为正，外层 $\exp$ + 负号保证 $\alpha_t \in (0, 1)$
  • $\odot$ 表示逐元素乘法
💡

直觉：$A_{\log}$ 设置每个头的衰减基准，$a_t$ 根据当前内容动态调制。话题切换时 $a_t$ 较大 $\to$ $\alpha_t$ 较小 $\to$ 快速遗忘；需要长期记忆时 $a_t$ 较小 $\to$ $\alpha_t \to 1$ $\to$ 保留历史。

2.3 两层门控的语义

  • $\alpha_t$（全局门控）：控制历史信息的整体保留率。$\alpha_t \to 0$ 时快速清空记忆（话题切换），$\alpha_t \to 1$ 时保留全部历史
  • $\beta_t$（局部更新强度）：控制新信息的写入力度。$\beta_t \to 1$ 时完全覆盖旧记忆

两者正交解耦：公式中 $\alpha_t$ 乘在 $(I - \beta_t k_t k_t^\top)$ 整体外面，意味着先做局部精准擦除-写入，再对整体做全局衰减。

2.4 与前代模型的关系

模型状态更新公式与 GDN 的关系
线性 RNN$S_t = S_{t-1} + v_t k_t^\top$GDN 中 $\alpha_t=1, \beta_t=1$ 的退化
Mamba2$S_t = \alpha_t S_{t-1} + v_t k_t^\top$GDN 中 $\beta_t \to 0$ 的退化
DeltaNet$S_t = S_{t-1} + \beta_t(v_t - S_{t-1}k_t)k_t^\top$GDN 中 $\alpha_t = 1$ 的退化
Gated DeltaNet$S_t = S_{t-1}\big(\alpha_t(I - \beta_t k_t k_t^\top)\big) + \beta_t v_t k_t^\top$统一全局遗忘 + 局部精确更新

三、q k v 的角色变化

3.1 传统 Attention 中

$$O = \text{softmax}(QK^\top / \sqrt{d})\, V$$

  • q：与所有 k 做点积，算"该关注谁"
  • k：被所有 q 匹配，决定"有多相关"
  • v：被注意力权重加权求和，是"输出内容"

核心特征：所有 token 同时存在，两两交互，复杂度 $O(L^2)$。

3.2 GDN 中

q k v 仍由 hidden_states 线性投影得到，但作用完全改变：

写入（k 和 v）：

$$\beta_t v_t k_t^\top \quad \text{-- 写入新信息}$$

  • $k_t$ 不再用于"被匹配"，而是作为写入地址：$k_t k_t^\top$ 形成低秩投影算子，定位要修改的记忆位置
  • $v_t$ 不再被"加权聚合"，而是作为写入内容，通过外积 $v_t k_t^\top$ 叠加到 $S$ 上

擦除（k 的第二作用）：

$$S_{t-1} \cdot \beta_t k_t k_t^\top \quad \text{-- 擦除旧信息}$$

  • $k_t k_t^\top$ 把 $S_{t-1}$ 中与 $k_t$ 方向对齐的部分"抠掉"

读取（q）：

$$o_t = S_t\, q_t \quad \text{-- 读取记忆}$$

  • $q_t$ 不再与任何 k 做点积，而是直接乘状态矩阵 $S_t$
  • 这是一次矩阵-向量乘法，$O(d_v \cdot d_k)$

3.3 对比总结

传统 AttentionGated DeltaNet
q 的作用与所有 k 算权重乘状态矩阵读取 $o_t = S_t q_t$
k 的作用被 q 匹配写入地址 + 擦除算子 $k_t k_t^\top$
v 的作用被加权聚合写入内容 $v_t k_t^\top$
交互方式token 间两两交互通过共享状态矩阵 $S$ 间接交互
复杂度$O(L^2 d)$$O(L \cdot d_v d_k)$

3.4 Delta Rule 的在线学习解释

把 $S$ 看作关联记忆，存储 $k \to v$ 的映射。Delta rule 本质是在线梯度下降：

  1. 当前预测：$\hat{v}_t = S_{t-1} k_t$
  2. 误差：$e_t = v_t - \hat{v}_t = v_t - S_{t-1} k_t$
  3. 梯度下降更新：

$$S_t = S_{t-1} + \beta_t\, e_t\, k_t^\top = S_{t-1} + \beta_t(v_t - S_{t-1}k_t)k_t^\top$$

展开整理：

$$S_t = S_{t-1}(I - \beta_t k_t k_t^\top) + \beta_t v_t k_t^\top$$

这正是 GDN 公式中 $\alpha_t = 1$ 的特例。$\beta_t$ 就是在线学习的学习率。

四、$\alpha$ 全局门控的时序特性

4.1 生成方式：内容驱动，非位置驱动

$\alpha_t$ 不依赖位置编码，而是 data-dependent（内容相关）的。从 Qwen 实现看：

python 
# A_log: 可学习参数 [num_v_heads]
# dt_bias: 可学习偏置 [num_v_heads]
# a, b: 由当前 token 的 hidden_states 投影得到

g = -exp(A_log) * softplus(a + dt_bias)
alpha_t = exp(g)   # ∈ (0, 1)

模型学会的是"看到某些内容时该遗忘多少"，而非"到了第几个位置就该遗忘"。

4.2 作用效果：时序指数衰减

$\alpha_t$ 作用于递推 $S_{t-1} \to S_t$，效果上是时序的。从第 $i$ 个 token 到第 $t$ 个 token，信息保留比例为：

$$\text{保留率} = \prod_{s=i+1}^{t} \alpha_s$$

若区间内 $\alpha$ 恒等于 $\alpha$，则保留率 $= \alpha^{t-i}$，呈指数衰减。

问题答案
$\alpha_t$ 是否依赖位置编码？否，由 token 内容计算
$\alpha_t$ 是否随时间步变化？是，每个 token 有不同 $\alpha_t$
$\alpha$ 的效果是否时序相关？是，通过递推产生指数衰减
衰减率是否固定？否，模型可按内容动态调整

五、实现细节

源码位于 transformers/models/qwen3_next/modeling_qwen3_next.py 的 Qwen3NextGatedDeltaNet 类。

5.1 投影与拆分

text 
hidden_states -> in_proj_qkvz -> q, k, v, z  (query/key/value/output_gate)
             -> in_proj_ba    -> b, a          (用于计算 β 和 α 的门控参数)
  • in_proj_qkvz: Linear(hidden_size, key_dim*2 + value_dim*2)，投影出 q, k, v, z
  • in_proj_ba: Linear(hidden_size, num_v_heads*2)，投影出 b, a
  • Qwen3-Next 配置：64 个 value 头、16 个 key 头，头维度 128

通过 fix_query_key_value_ordering 函数将混合投影输出拆分为结构化的多头 Q、K、V、Z 矩阵及门控参数 b、a。

5.2 $\alpha$ 和 $\beta$ 的计算

$\alpha$（全局遗忘门）和 $\beta$（局部更新强度）都是 data-dependent（内容驱动）的，由当前 token 的 hidden_states 投影后经非线性变换得到。

5.2.1 $\beta$ 的计算（局部更新强度 / 输入门）

$\beta$ 由投影得到的 b 经 sigmoid 激活得到：

python 
beta = b.sigmoid()   # β ∈ (0, 1)
  • b 来自 in_proj_ba 投影，shape 为 [batch, seq_len, num_v_heads]
  • sigmoid 保证 $\beta \in (0, 1)$
  • 每个 value head 独立一个 $\beta$ 标量
  • $\beta$ 控制新信息的写入强度：$\beta \to 1$ 完全覆盖旧记忆，$\beta \to 0$ 不写入

5.2.2 $\alpha$ 的计算（全局遗忘门 / 衰减率）

$\alpha$ 的计算更复杂，融合了可学习参数和数据相关参数：

python 
# 可学习参数（每个 value head 一组，所有 token 共享）
A_log = log(A)       # A ~ Uniform(0, 16), 初始化时采样
dt_bias = ones(num_v_heads)  # 可学习偏置

# 数据相关参数（由当前 token 内容投影得到）
a   # 来自 in_proj_ba, shape [batch, seq_len, num_v_heads]

# 计算衰减速率 g
g = -exp(A_log) * softplus(a + dt_bias)    # g < 0

# 转换为门控值 α
alpha = exp(g)   # α ∈ (0, 1)

数学表达：

$$\alpha_t = \exp\Big(-\exp(A_{\log}) \cdot \text{softplus}(a_t + dt_{bias})\Big)$$

各组件的作用：

组件类型作用
$A_{\log}$可学习参数 [num_v_heads]控制每个头的基础衰减率，初始化为 $\log(\text{Uniform}(0, 16))$
$dt_{bias}$可学习偏置 [num_v_heads]对衰减速率的偏移修正，初始化为 1
$a_t$数据相关由当前 token 内容投影，实现内容驱动的动态衰减
$\text{softplus}$非线性激活保证衰减速率为正（$\text{softplus}(x) > 0$）
外层 $\exp$ + 负号约束保证 $\alpha \in (0, 1)$，即可作为门控值

5.2.3 设计直觉

这个计算方式借鉴了 Mamba 的离散化方案（SSM 中的 $\Delta t$ 离散化）：

  1. $A_{\log}$（基础衰减率）：每个头有一个全局可学习的衰减基准。取指数后 $\exp(A_{\log})$ 是正实数，表示"单位时间的衰减速率"。初始化范围 $(0, 16)$ 使得初始衰减速率覆盖从快遗忘到慢遗忘的各种模式。
  2. $\text{softplus}(a_t + dt_{bias})$（内容调制）：softplus 保证为正，a_t 由 token 内容决定衰减的加速/减速：
    • 话题切换时 $a_t$ 较大 $\to$ $\text{softplus}$ 较大 $\to$ $g$ 更负 $\to$ $\alpha$ 更小 $\to$ 快速遗忘
    • 需要长期记忆时 $a_t$ 较小 $\to$ $\text{softplus}$ 接近 0 $\to$ $g$ 接近 0 $\to$ $\alpha$ 接近 1 $\to$ 保留记忆
  3. 乘积形式 $-\exp(A_{\log}) \cdot \text{softplus}(\cdot)$：基础衰减率与内容调制的乘积，使得衰减既受头的全局特性控制，又受当前内容动态调节。

5.2.4 fp32 精度要求

$\alpha$ 的计算强制在 fp32 下进行：

python 
g = -self.A_log.exp() * F.softplus(a.float() + self.dt_bias)
⚠️

原因：$A_{\log}$ 取指数后，bf16 的舍入误差会变成衰减率的比例误差，而这个误差会在递推过程中被逐级放大（每步乘一次 $\alpha$，误差累积）。因此 NVIDIA 的 NeMo 实现中专门创建了 Qwen3NextFp32GatedDeltaNet 子类，将 A_log/dt_bias 放入 native fp32 holder，确保门控计算全程在 fp32 下执行。

5.3 因果一维卷积（Causal Conv1d, K=4）

在进入递归之前，对 Q/K/V 拼接后做深度因果卷积，捕获局部依赖：

python 
self.conv1d = nn.Conv1d(
    in_channels=self.conv_dim,
    out_channels=self.conv_dim,
    bias=False,
    kernel_size=self.conv_kernel_size,  # 4
    groups=self.conv_dim,               # depthwise
    padding=self.conv_kernel_size - 1,
)

引入卷积的原因：

  • 补足线性注意力在局部模式建模上的弱点
  • 比 attention 便宜（$O(n)$ vs $O(n^2)$）
  • 具备平移不变性，适合固定短语、边界模式

5.4 双模式算子

系统提供两套实现，运行时自动选择高性能版本：

算子用途说明
causal_conv1d_fn训练/全序列CUDA fused 因果卷积
causal_conv1d_update增量推理用 conv_state 缓存，O(1) 单步
chunk_gated_delta_rule训练/预填充分块并行计算 delta rule
fused_recurrent_gated_delta_rule逐 token 解码纯递归形式，固定状态

每个算子有高性能 Triton/CUDA 版本和 PyTorch 参考版本（回退方案），两者计算等价。

5.5 数值稳定性优化

  • fp32 门控计算：A_log/dt_bias 放入 native fp32 holder，避免 bf16 舍入误差在递推中被放大
  • 零中心化 RMSNorm：替代传统 QK-Norm，解决归一化权重异常增长
  • 权重衰减的 LayerNorm：增强预训练稳定性
  • padding 清零：apply_mask_to_padding_states 防止 padding token 污染递归状态

六、Chunkwise 并行训练的完整推导

6.1 问题：纯递推无法并行

纯递推 $S_t = f(S_{t-1}, x_t)$ 必须串行执行 $L$ 步，GPU 利用率极低。

需要将递推转换为可并行的矩阵运算，且保持数学精确性（无近似）。

6.2 推导起点：引入"修正值" $u_t$

为简化推导，先考虑 $\alpha_t = 1$（纯 DeltaNet）的情况。

定义中间变量（修正后的值）：

$$u_t = \beta_t(v_t - S_{t-1} k_t)$$

则递推变为：

$$S_t = S_{t-1} + u_t k_t^\top$$

$S_t$ 是 $S_0$ 加上一系列秩-1 修正的累加：

$$S_t = S_0 + \sum_{i=1}^{t} u_i k_i^\top$$

6.3 发现 $u_t$ 满足线性方程组

将 $S_{t-1} = S_0 + \sum_{i=1}^{t-1} u_i k_i^\top$ 代入 $u_t$ 定义：

$$u_t = \beta_t v_t - \beta_t S_0 k_t - \beta_t \sum_{i=1}^{t-1} u_i (k_i^\top k_t)$$

关键观察：$k_i^\top k_t$ 是标量。

将 $C$ 个 $u_t$ 堆叠成矩阵 $U = [u_1; u_2; ...; u_C] \in \mathbb{R}^{C \times d_v}$，写成矩阵形式：

$$U = \text{diag}(\beta)\,V - \text{diag}(\beta)\,K\,S_0^\top - \text{diag}(\beta)\,\underbrace{(K K^\top \odot M_{strict})}_{C \times C}\,U$$

其中：

  • $K = [k_1; ...; k_C] \in \mathbb{R}^{C \times d_k}$
  • $V = [v_1; ...; v_C] \in \mathbb{R}^{C \times d_v}$
  • $K K^\top \in \mathbb{R}^{C \times C}$：所有 key 的两两点积
  • $M_{strict}$：严格下三角掩码（保证因果性）

整理得：

$$\big[I + \text{diag}(\beta)\,(K K^\top \odot M_{strict})\big]\,U = \text{diag}(\beta)\,(V - K S_0^\top)$$

6.4 核心结果：$d_k \times d_k$ 连乘转换为 $C \times C$ 求逆

定义：

$$\boxed{P = I + \text{strictLower}\big(\text{diag}(\beta)\,K K^\top\big) \in \mathbb{R}^{C \times C}}$$

则：

$$\boxed{U = P^{-1}\,\text{diag}(\beta)\,(V - K S_0^\top)}$$
🎯

$d_k \times d_k$ 的矩阵连乘，变成了 $C \times C$ 矩阵 $P$ 的求逆。 这是整个 chunkwise 并行的核心。

6.5 块内输出与块末状态

有了 $U$，块内输出和块末状态都可以用矩阵乘法算出：

块内输出 $O = [o_1; ...; o_C]$：

$$o_t = S_t q_t = \big(S_0 + \sum_{i=1}^{t} u_i k_i^\top\big) q_t = S_0 q_t + \sum_{i=1}^{t} u_i (k_i^\top q_t)$$

矩阵形式：

$$\boxed{O = Q\,S_0^\top + (Q K^\top \odot M)\,U}$$

其中 $Q = [q_1; ...; q_C] \in \mathbb{R}^{C \times d_k}$，$M$ 是下三角因果掩码。

块末状态 $S_C$：

$$\boxed{S_C = S_0 + U^\top K}$$

6.6 分离 $S_0$ 相关项

令 $\tilde{U} = P^{-1}\text{diag}(\beta)V$，$\tilde{W} = P^{-1}\text{diag}(\beta)K$，则 $U = \tilde{U} - \tilde{W}S_0^\top$。

代入输出公式：

$$O = \big[Q - (QK^\top \odot M)\tilde{W}\big]\,S_0^\top + (QK^\top \odot M)\tilde{U}$$

代入状态公式：

$$S_C = S_0\big(I - \tilde{W}^\top K\big) + \tilde{U}^\top K$$

$S_0$ 相关项和无关项分离，块间只需传递 $S_0$。

6.7 加入 $\alpha$ 门控的扩展

加入 $\alpha_t$ 后，递推变为：

$$S_t = \alpha_t\, S_{t-1}(I - \beta_t k_t k_t^\top) + \beta_t v_t k_t^\top$$

$\alpha_t$ 的效果是给每步乘一个标量衰减，展开后衰减累积为：

$$\Gamma_{ij} = \prod_{s=i+1}^{j} \alpha_s \quad (i < j)$$

这是 $C \times C$ 的衰减掩码，替代原来的 $\{0,1\}$ 因果掩码 $M$。公式形式不变，只是掩码从二值变成连续值：

$$P = I + \text{strictLower}\big(\text{diag}(\beta)\,(\Gamma \odot K K^\top)\big)$$

✅

$\Gamma$ 可预先算出（$\alpha_t$ 在前向时已知），仍然精确，无近似。

6.8 计算量对比

方案块内计算块间总计算量

⚡

七、如何减少计算量

7.1 复杂度从 $O(L^2)$ 降到 $O(L)$

标准注意力计算和显存都是 $O(L^2)$。GDN 用固定大小状态矩阵 $S \in \mathbb{R}^{d_v \times d_k}$ 做递推，每个 token 只需 $O(d_v \cdot d_k)$，总复杂度 $O(L)$。

  • 4K $\to$ 256K：标准注意力计算量增加 4096 倍，GDN 仅增加 64 倍

7.2 推理时固定大小缓存

标准 Transformer 推理时 KV cache 随序列线性增长。GDN 的递归状态 $S_t$ 大小恒定（$d_v \times d_k$），与序列长度无关：

  • 增量解码时每步只需更新固定矩阵，$O(1)$ 单步开销
  • conv_state 固定为 kernel_size - 1 长度
  • 256K 上下文下显存峰值从 78GB 压到 42GB（FP16, A100-80G）

7.3 Chunkwise 并行解决训练并行性

纯递推无法利用 GPU 并行。chunkwise 方案把序列切成块：

  • 块内：$C \times C$ 矩阵运算高度并行
  • 块间：只递推小状态矩阵 $S$
  • chunk size $C$ 是核心调参点（通常 64-128）

7.4 混合架构只保留 25% 全注意力

48 层中仅 12 层用标准 GQA，其余 36 层用 GDN：

  • 75% 的层享受 $O(L)$ 复杂度和固定缓存
  • 25% 的层提供高精度全局交互
  • 4K 上下文预填充场景实现近 7 倍加速

7.5 与超稀疏 MoE 协同

Qwen3-Next 的 MoE 有 512 个专家、仅激活 10+1 个，激活率 3.7%。GDN 的低计算开销与稀疏 MoE 叠加，使 80B 总参数模型仅激活 3B 参数，整体推理速度提升约 10 倍。

八、统一视角：RNN、Mamba、Transformer 的等价关系

8.1 统一框架：都是"状态压缩 + 检索"

模型状态更新读取压缩方式
线性 RNN$S_t = S_{t-1} + v_t k_t^\top$$o_t = S_t q_t$纯累加，无遗忘
Mamba2$S_t = \alpha_t S_{t-1} + v_t k_t^\top$$o_t = S_t q_t$累加 + 标量遗忘
DeltaNet$S_t = S_{t-1}(I-\beta_t k_t k_t^\top) + \beta_t v_t k_t^\top$$o_t = S_t q_t$delta rule（擦除+写入）
Gated DeltaNet上式 + $\alpha_t$$o_t = S_t q_t$delta rule + 门控遗忘
Transformer无显式状态$o_t = \sum_j \text{softmax}(q_t^\top k_j) v_j$不压缩，保留全部历史

8.2 精确等价关系

  1. 线性 Attention $\equiv$ 线性 RNN（精确）：Katharopoulos et al. (2020) 证明，用线性核替代 softmax 后，attention 可精确重写为 RNN
  2. Mamba2 $\equiv$ 带门控的线性 Attention（精确）：Mamba2 论文（Dao & Gu, 2024）建立双向映射
  3. GDN = 线性 Attention + delta rule 修正：$\beta \to 0$ 时退化为线性 attention
  4. Softmax Attention $\approx$ 线性 Attention（近似）：当 attention 分布较平坦时成立

8.3 Chunk Size 连续谱

RNN 和 Transformer 是 chunk size 谱的两个端点：

text 
C = 1                          C = L
 |                               |
 v                               v
纯 RNN                       Full Attention
完全串行                      完全并行
O(L) 计算量                  O(L²) 计算量
零块内交互                   全部 token 交互
状态固定大小                 保留全部 KV
  • $C = 1$：每步一个 token，纯递推（RNN/Mamba 推理模式）
  • $C = L$：整个序列一个块，$L \times L$ 矩阵运算（Attention）
  • $1 < C < L$：chunkwise，块内并行 + 块间递推（GDN/Mamba2 训练模式）

8.4 不同模型的块内交互矩阵

模型块内 $C \times C$ 矩阵含义
Linear Attention$QK^\top$query-key 读取交互
Mamba2$\Gamma \odot QK^\top$带衰减的读取交互
GDN$P^{-1}$ 涉及 $\Gamma \odot KK^\top$写入交互 + 读取交互
Softmax Attention$\text{softmax}(QK^\top)$非线性读取交互

GDN 多了 $KK^\top$ 是因为 delta rule 的擦除操作——写入新 key 时要考虑与旧 key 的冲突。纯加法模型（RNN/Mamba）没有这个项。

8.5 GDN 与 Attention 的形式对比

当 $\beta$ 很小时，$P \approx I$，$U \approx \text{diag}(\beta) V$，GDN 的 chunkwise 输出退化为：

$$O \approx Q S_0^\top + (Q K^\top \odot M)\,\text{diag}(\beta)\,V$$

这几乎就是 causal linear attention：$(QK^\top \odot M) V$。

$P^{-1}$ 的修正项涉及 $KK^\top$，捕获的是"key 之间的写入冲突"：

  • Attention 的 $QK^\top$：读取时交互（query 选 key）
  • GDN 的 $KK^\top$：写入时交互（新 key 擦除旧 key）

九、用到的数学工具总结

数学工具在哪里用作用
秩-1扰动结构$A_t = I - \beta_t k_t k_t^\top$连乘可降维到 $C \times C$
外积求和$S_t = S_0 + \sum u_i k_i^\top$把矩阵递推变成向量序列

📌

核心一句话：利用 $A_t = I - \beta_t k_t k_t^\top$ 的秩-1结构，把 $d_k \times d_k$ 的矩阵连乘等价转换为 $C \times C$ 的线性方程组求解，从而把计算量从 $O(C \cdot d_k^3)$ 降到 $O(C^2 d_k + C^3)$，同时获得并行性。
